# 模板营销化命名实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将四个模板的用户可见名称统一替换为已确认的营销结果型名称。

**Architecture:** 保持稳定模板 ID 和 API 合同不变，只更新前端标签、后端 Mock 展示文案及项目说明。历史记录继续使用原模板 ID，无需迁移。

**Tech Stack:** React、TypeScript、Express、Vite

## Global Constraints

- `ip-image`、`travel-cards`、`scenery-collage`、`people-collage` 四个模板 ID 不变。
- 不修改请求和响应结构，不迁移浏览器历史。
- 新名称依次为：IP 宣传海报、攻略种草卡、景区氛围大片、人物打卡大片。
