### Task 2: 一句话创作输入壳

**Files:**
- Create: `frontend/src/features/home/HomeComposer.tsx`
- Create: `frontend/src/features/home/HomeComposer.test.tsx`
- Create: `frontend/src/styles/home-composer.css`

**Interfaces:**
- Produces: `HomeAttachment = {id:string; name:string; previewUrl:string; status:'pending'|'uploading'|'uploaded'|'failed'}`
- Produces: `HomeComposerProps = {prompt:string; attachments:readonly HomeAttachment[]; busy?:boolean; error?:string; onPromptChange(value:string):void; onAddFiles(files:File[]):void; onRemoveAttachment(id:string):void; onSubmit():void}`
- Produces: `HomeComposer(props:HomeComposerProps): JSX.Element`

- [ ] **Step 1: 写交互失败测试**

覆盖：

- 空输入和 1 字输入时向上箭头 disabled。
- 输入 2 字后按 Enter 调用一次 `onSubmit`，不向 textarea 插入换行。
- Shift+Enter 不调用提交。
- `nativeEvent.isComposing=true` 时 Enter 不调用提交。
- 点击加号触发隐藏文件输入；选择文件后把 `File[]` 交给 `onAddFiles` 并清空 input value。
- 点击缩略图移除按钮传递对应 attachment id。
- `busy=true` 时两按钮禁用，`aria-live` 显示“正在生成”。
- `error` 使用 `role="alert"`，不清空 prompt 或附件。

- [ ] **Step 2: 运行测试确认失败**

Run:

```bash
npx vitest run frontend/src/features/home/HomeComposer.test.tsx --config frontend/vitest.config.ts
```

Expected: FAIL，因为组件尚不存在。

- [ ] **Step 3: 实现受控组件**

组件不上传文件、不调用 API、不创建 Object URL。隐藏 input 接受 `image/jpeg,image/png,image/webp`、`multiple`；父层负责文件校验和 previewUrl 生命周期。文本域 `aria-label="一句话创作需求"`，加号 `aria-label="添加参考图片"`，箭头 `aria-label="开始生成"`。

键盘判定：

```ts
if(event.key!=='Enter'||event.shiftKey||event.nativeEvent.isComposing) return;
event.preventDefault();
if(canSubmit) onSubmit();
```

- [ ] **Step 4: 实现 90% 毛玻璃样式**

外层使用 `grid-template-columns:minmax(0,1fr) auto`；正文列到按钮列 `column-gap:20px`；按钮组 `gap:8px`；图标视觉 36px、点击区域 44px；附件为 44×44px 紧凑缩略图。移动端只把列间距降为 16px，不把按钮移到输入框下方。
