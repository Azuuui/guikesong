# 黔景智作正式首页集成 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将已完成的品牌、顶部毛玻璃导航、主页粒子背景与一句话输入壳接入正式产品，并让两个真实工作流、模板详情、结果和历史形成可运行的多页面闭环。

**Architecture:** `AppShell` 只负责全局顶部导航与页面内容承载；`DashboardPage` 变为主页编排层，由独立的主页生成控制器处理附件、API、历史保存和结果跳转。模板配置继续以 `WorkflowId` 为稳定标识，模板列表与详情页共享配置和预览组件；`/templates/:templateId/create` 仅保留为原创 IP 首次档案配置及历史恢复兜底，不再作为日常主入口。

**Tech Stack:** React 19、React Router 7、TypeScript 5.9、原生 CSS、Phosphor Icons、Vitest、Testing Library、IndexedDB、Canvas 2D。

## Global Constraints

- 品牌固定为“黔景智作 / QianScape AI / QSAI”，使用项目内官方 SVG。
- 当前模板只允许 `xhs-atlas` 与 `original-ip`；旧四模板不得恢复。
- 主页默认选择 `xhs-atlas`，`original-ip` 排在后面。
- 背景粒子动画只在 `/` 挂载，离开主页必须销毁。
- 顶部导航为全宽 60% 雾灰毛玻璃；主页输入框背景为 90% 不透明度。
- 点击主页模板只切换选择；“详情”进入 `/templates/:templateId`。
- `Enter` 提交，`Shift + Enter` 换行，输入法组词期间不得误提交。
- 小红书图鉴可从主页直接生成；原创 IP 已有锁定档案时直接生成，没有锁定档案时保留输入与产品图并进入必要配置页。
- 结果、部分成功、历史保存、下载和恢复沿用现有双工作流合同。
- 不增加搜索、筛选、收藏、模板市场或新的后端工作流。
