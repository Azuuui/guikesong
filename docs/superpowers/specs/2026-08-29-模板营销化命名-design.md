# 模板营销化命名设计

> 日期：2026-08-29
> 状态：已实施

## 背景

现有模板名称偏内部功能描述，缺少明确的营销结果感。用户选择“营销结果型”命名，使业务人员能直接理解每个模板将生成什么素材。

## 命名映射

| 稳定模板 ID | 原展示名称 | 新展示名称 |
| --- | --- | --- |
| `ip-image` | 固定 IP 形象 | IP 宣传海报 |
| `travel-cards` | 旅游攻略知识卡片 | 攻略种草卡 |
| `scenery-collage` | 风景拼图 | 景区氛围大片 |
| `people-collage` | 人物拼图 | 人物打卡大片 |

## 实施范围

- 更新前端模板选择器的用户可见名称。
- 更新后端 Mock 生成结果中的模板名称、图片文字和标签。
- 同步项目介绍、PRD 及设计上下文中用于描述四类模板的业务名称。
- 保持模板 ID、请求和响应合同、历史数据键、文件名规则不变。

## 兼容性

本次只修改用户可见文案。既有历史记录仍按稳定模板 ID 识别，不迁移浏览器数据，也不修改 API 合同。

## 验收标准

- 模板选择区显示四个新名称，不再出现四个旧展示名称。
- 四类 Mock 生成结果分别使用对应新名称。
- `typecheck`、测试和生产构建通过。
- 浏览器刷新后显示新名称，四个模板均可正常提交生成。
