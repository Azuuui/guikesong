## 1. 文档定位

本文档定义黔景智作新一版首页、顶部导航、模板入口和一句话生成入口的最终 UX/UI 方向。它同时包含：

- UX：页面层级、页面职责、跳转、选择和生成流程。
- UI：毛玻璃材质、透明度、排版、宽度、间距、圆角、阴影、组件状态和响应式规则。
- 动效接入边界：为用户另行制作的页面背景动效预留稳定承载层，不定义动效具体画面。

本文档是后续界面改造的最新设计依据。它取代旧规范中与以下内容冲突的部分：固定侧边导航、任务优先工作台、独立模板创建页和首页最近任务区。结果详情、本机历史、下载、部分成功和参考图业务规则继续沿用既有 PRD。

本轮只确认设计，不修改产品代码。书面设计再次确认后，再编写实施计划，并在执行阶段同步主 PRD 与原 UX/UI 规范。

## 2. 设计目标

用户打开产品后，不需要先理解工作台、表单或模型参数，直接完成三件事：

1. 默认使用最常用模板。
2. 输入一句话，可选添加参考图。
3. 按 Enter 或点击生成，进入独立结果页。

整体气质采用“产品化电子杂志”：页面有清晰的编辑感和文旅气质，但保持产品可用性。未来动态背景负责氛围，导航和生成输入区用克制的毛玻璃材质建立可读层级。

└── 历史详情 `/history/:recordId`

页面职责：

- 主页承担完整生成入口，不展示最近任务、数据统计或工作台卡片。
- 全部模板负责浏览和比较模板，不承担生成表单。
- 模板详情负责解释单个模板，不重复放置完整生成表单。
- 结果详情负责查看、复制和下载。
- 历史记录只从顶部右侧历史图标进入。
- 不再保留 `/templates/:templateId/create` 作为主要用户路径；所有模板最终回到主页生成。

## 5. 页面总体结构

页面从后向前分为四层：

1. `BackgroundMotionLayer`：未来动态背景，铺满视口。
2. 页面内容层：首页标题和模板内容。
3. 毛玻璃表面层：顶部导航、当前页签、生成输入框。
4. 浮层：菜单、提示、沉浸预览和对话框。

桌面端宽度：

- 顶部导航：`100vw`，从左到右铺满，不设外层圆角。
- 首页主内容：`min(90vw, 1440px)`。
- 标题和生成输入区：`min(76vw, 1040px)`。
- 常用模板轨道：使用首页主内容全宽，不与标题列一起缩成窄栏。
- 页面左右最小安全边距：32px；1600px 以上不继续无限放大内容。

纵向节奏：

- 顶部导航高度：72px。
- 首页主内容顶部留白：`clamp(112px, 15vh, 176px)`。
- 眉题到主标题：12px。
- 主标题两行内部行距：1.12 倍。
- 主标题到辅助说明：16px。
- 辅助说明到生成输入框：24px。
- 生成输入框到常用模板区：44px。
- 常用模板标题到卡片轨道：16px。

目标是形成舒展的横向画布，而不是把所有内容挤在页面中心的小卡片中。

## 6. 顶部导航

### 6.1 布局

顶部导航固定在视口上方，分为三段：

| 位置 | 内容 | 对齐规则 |
|---|---|---|
| 左侧 | QSAI + 黔景智作 + QianScape AI | 左对齐，品牌区不参与中部居中计算 |
| 中部 | 主页 / 全部模板 | 以视口绝对水平中心定位 |
| 右侧 | 历史记录图标 | 右对齐，纯图标按钮 |

中部导航必须相对整个视口居中，不能因为左右内容宽度不同产生偏移。

### 6.2 导航毛玻璃

顶部导航最终背景透明度为 60%。推荐实现 Token：

```css
--glass-nav-bg: rgb(246 248 247 / 60%);
--glass-nav-blur: 20px;
--glass-nav-saturation: 140%;
--glass-nav-border: rgb(255 255 255 / 42%);
--glass-nav-shadow: 0 1px 0 rgb(20 20 20 / 8%);
```

表现规则：

- 导航从左到右全宽铺开，不使用外层圆角。
- 只保留底部 1px 柔和分隔，不使用悬浮大阴影。
- 透明度只作用于背景层；品牌、文字和图标保持 100% 不透明。
- `backdrop-filter` 不可用时，退化为不透明度更高的浅雾灰背景，仍保证文字可读。

### 6.3 中部活动页签

“主页 / 全部模板”使用接入导航底边的活动页签，而不是独立悬浮胶囊：

- 当前页签顶部为圆角椭圆轮廓。
- 页签底边与导航最底部严格平齐，不能向页面内容区延伸。
- 页签左右使用短而平滑的连接翼过渡到导航底边。
- 非当前项保持透明，只显示文字和轻量悬停反馈。
- 当前项使用带透明度的雾灰，不使用纯白实心块。

最终 Token：

```css
--glass-tab-active-bg: rgb(232 236 234 / 78%);
--glass-tab-active-border: rgb(255 255 255 / 48%);
--glass-tab-active-radius: 999px 999px 0 0;
```

活动页签高度 44px，顶部圆角采用全圆角语义，底部圆角为 0。页签文字 14px/20px、字重 600；当前项使用主文字色，非当前项使用辅助文字色。

连接翼的几何约束：

- 当前项主体宽度以文字宽度加左右各 24px 内边距计算。
- 左右连接翼各向外延伸 20px，高度 12px，只存在于导航内部的底边区域。
- 连接翼与主体使用同一雾灰背景，通过四分之一圆曲线接入导航底边。
- 主体、连接翼和导航底边的最低点共用同一条 72px 基线；任何伪元素都不得超出导航边界。

### 6.4 历史入口

- 右侧只显示一个历史图标，不放“历史记录”常驻文字。
- 点击区域不小于 44×44px，图标 20px，线宽统一。
- 必须提供 `aria-label="历史记录"` 和悬停提示。
- 当前处于历史页时，图标显示轻量选中态，但不占用中部活动页签。

## 7. 首页文字排版

首页标题采用三层信息：

```text
QIANSCAPE AI · TRAVEL CREATIVE STUDIO

从一句话开始，
生成一套文旅表达。

输入地点、主题和想要传达的感觉
```

排版层级：

| 角色 | 字体建议 | 桌面字号/行高 | 字重 | 说明 |
|---|---|---:|---:|---|
| 英文眉题 | 等宽字体栈 | 11px / 16px | 500 | 字距 0.12em，弱化呈现 |
| 中文主标题 | 现代中文衬线字体栈 | `clamp(40px, 4.2vw, 68px)` / 1.12 | 500 | 两行，避免粗黑大标题 |
| 辅助说明 | 中文无衬线字体栈 | 15px / 24px | 400 | 限宽、低对比度 |
| 产品正文 | 中文无衬线字体栈 | 14px / 22px | 400 | 表单、详情和反馈 |

字体栈原则：

- 标题优先使用系统可用的中文宋体/现代衬线字体，缺失时稳定回退。
- 正文和控件使用无衬线字体，保证长时间阅读和交互清晰。
- 元数据使用等宽字体，只用于英文眉题、编号和短标签。
- 不在标题旁堆叠图标、标签和解释性按钮。
- 首版不依赖在线字体服务，建议字体栈如下：

```css
--font-display: "Songti SC", "Noto Serif CJK SC", "Source Han Serif SC", serif;
--font-sans: "PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", system-ui, sans-serif;
--font-mono: "SFMono-Regular", Menlo, Consolas, monospace;
```

## 8. 一句话生成输入框

### 8.1 结构

生成输入框是首页唯一主交互，内部只保留：

- 多行文字输入。
- `＋` 添加图片按钮。
- `↑` 生成按钮。

不显示模型选择、参数设置、提示词配置或额外主按钮。

默认结构采用两列网格：

```text
┌──────────────────────────────────────────────────────────┐
│ 输入一句话需求……                         ＋   ↑          │
└──────────────────────────────────────────────────────────┘
```

最终尺寸：

| 参数 | 数值 |
|---|---:|
| 默认最小高度 | 68px |
| 横向内边距 | 左 18px / 右 14px |
| 纵向内边距 | 14px |
| 文字区与右侧按钮组间距 | 20px |
| 按钮组内部间距 | 8px |
| 图标按钮视觉尺寸 | 36×36px |
| 图标按钮可点击区域 | 不小于 44×44px |
| 文本字号/行高 | 15px / 24px |
| 最大自动增长高度 | 168px |

输入文字和右侧按钮组最终使用 20px 间距。布局禁止使用 `justify-content: space-between` 制造不可控的大空白；文字列用 `minmax(0, 1fr)`，按钮组保持内容宽度。

### 8.2 输入框毛玻璃

输入框背景最终不透明度为 90%，比顶部导航更实，以保证长文本可读：

```css
--glass-composer-bg: rgb(250 251 250 / 90%);
--glass-composer-blur: 16px;
--glass-composer-border: rgb(255 255 255 / 62%);
--glass-composer-shadow:
  0 1px 2px rgb(20 20 20 / 5%),
  0 14px 36px rgb(20 20 20 / 10%);
--glass-composer-radius: 18px;
```

规则：

- 90% 只作用于输入框背景；输入文字、占位符、图标和焦点环不透明。
- 默认使用细边界和低阴影，聚焦时增加品牌红焦点环，不使用霓虹外发光。
- 输入框圆角 18px，只用于这一主交互；普通业务卡片不得跟随放大圆角。
- 输入变长时向下增长，右侧按钮组贴近输入区域的垂直中线或底部，不漂到远处。

### 8.3 图片附件

- 点击 `＋` 选择图片，继续沿用最多 4 张、JPG/PNG/WebP、单张不超过 10MB 的业务限制。
- 已选图片以 44×44px 紧凑缩略图显示在输入框内部下方，不另起大型上传卡片。
- 单张图片提供移除按钮和明确上传/失败状态。
- 图片区出现后，文字区与图片区间距 12px；按钮组仍位于右侧，不与缩略图混排。

### 8.4 键盘和提交

- `Enter`：直接开始生成。
- `Shift + Enter`：换行。
- 中文输入法正在组词时，`Enter` 只确认候选字，不得误提交。
- 点击 `↑` 与按 Enter 调用同一提交逻辑。
- 输入去除首尾空白后少于 2 个字符时，生成按钮禁用并显示就地说明。
- 生成中禁止重复提交，箭头切换为紧凑加载状态并显示“正在生成”。
- 生成成功或部分成功后进入 `/results/:requestId`。
- 失败时保留文字、模板和仍有效的参考图，在输入框下方显示可恢复错误。

## 9. 常用模板

### 9.1 最终排序

常用模板按以下顺序固定展示：

1. 攻略种草卡（`travel-cards`）
2. 景区氛围大片（`scenery-collage`）
3. 人物打卡大片（`people-collage`）
4. IP 宣传海报（`ip-image`）

首页首次进入时默认选中第一项“攻略种草卡”。用户无需额外点击模板，输入一句话即可生成。

模板展示名未来允许调整，但排序、选择和历史兼容必须依赖稳定模板 ID，不得依赖中文名称。

### 9.2 卡片结构

每张模板卡片采用“名称在上、图片在下”：

```text
攻略种草卡                         详情
┌────────────────────────────────────┐
│                                    │
│             模板预览图              │
│                                    │
└────────────────────────────────────┘
```

- 顶部名称 15px/22px、字重 600。
- “详情” 12px/18px、字重 500，使用辅助文字色；可见但不抢主视觉。
- 图片比例由模板配置提供，卡片使用统一预览容器避免跳动。
- 卡片不放长描述、功能标签或大号操作按钮。
- 选中态使用 1px 强调边界和小型勾选标识，不使用整卡高饱和填充。

### 9.3 横向轨道

- 桌面端单卡建议宽度 260—300px，间距 20px。
- 轨道使用横向滚动和 `scroll-snap`，支持触控板、鼠标滚轮横向转换和触摸滑动。
- 有溢出时显示克制的左右翻页按钮；没有溢出时隐藏。
- 轨道两端不使用遮挡卡片文字的重渐变。
- 手机端允许看到下一张卡片的一部分，提示用户可以横向滑动。

### 9.4 点击规则

- 点击图片或模板名称：只切换当前模板，留在主页。
- 点击“详情”：进入 `/templates/:templateId`。
- 切换模板不清空已输入文字和已选参考图。
- 当前模板 ID 与生成请求保持一致。

## 10. 全部模板与模板详情

### 10.1 全部模板

顶部中部“全部模板”处于活动页签状态。每张模板提供两个层级明确的操作：

- 使用模板：回到主页，自动选中该模板并聚焦生成输入框。
- 查看详情：进入该模板的独立详情页。

全部模板页可容纳后续新增工作流入口，但本轮不增加搜索、筛选、收藏、推荐或模板市场。

### 10.2 模板详情

模板详情至少包含：

- 大幅预览图。
- 模板用途和适用场景。
- 一句话输入建议。
- 示例输入和预期输出说明。
- “用此模板创作”主操作。

点击“用此模板创作”后返回主页、选中当前模板并聚焦生成输入框。详情页不重复上传区和生成表单。

模板详情属于“全部模板”体系：进入详情后，中部“全部模板”仍保持活动归属，用户可以从浏览器返回或页面返回入口回到模板列表。

## 11. 结果与历史

- 新生成和部分成功结果进入独立结果详情，不向主页下方追加结果。
- 结果详情继续复用已有缩略图、主图、文案、复制、下载和沉浸预览能力。
- 成功或部分成功结果继续写入本机 IndexedDB。
- 历史列表和历史详情继续保留单条删除、清空、复制和下载能力。
- 首页不展示最近历史；历史统一从顶部右侧图标进入。
- 返回首页时保留默认或最近明确选择的模板；不自动把历史模板当作新的默认排序。

## 12. 视觉 Token

### 12.1 色彩

```css
--color-brand-red-700: #b6000e;
--color-brand-red-600: #e60012;
--color-brand-red-100: #ffe3e5;
--color-ink-900: #141414;
--color-ink-700: #363636;
--color-ink-500: #6a6a6a;
--color-secondary-teal: #1f6761;
--color-border-soft: rgb(0 0 0 / 12%);
--color-focus: rgb(230 0 18 / 32%);
```

品牌红 `#E60012` 是页面唯一主操作色：用于生成按钮、模板选中边界、小型勾选和键盘焦点。悬停或按下使用 `#B6000E`，浅选中背景使用 `#FFE3E5`。白色文字位于品牌红按钮上时必须保持清晰对比。

青绿色 `#1F6761` 降为辅助色，只允许用于少量文旅内容提示或非主操作信息，不用于生成按钮、当前模板、导航活动页签或主要焦点。顶部活动页签继续使用已确认的透明雾灰。

未来背景动效可以提供文旅色彩，但前景控件不增加紫色霓虹、外发光或其他竞争主色。

### 12.2 间距

沿用 4px 网格：4、8、12、16、20、24、32、40、44、48、64px。新增的 44px 仅用于本设计中输入框到模板区的页面节奏和最小点击区域，不作为通用组件内边距。

同一信息组优先 8—12px；同一组件的主要区域优先 16—20px；页面区块优先 32—48px。

### 12.3 圆角

| Token | 数值 | 用途 |
|---|---:|---|
| `--radius-sm` | 6px | 小标签、缩略图内部元素 |
| `--radius-md` | 10px | 普通按钮、小型控件 |
| `--radius-lg` | 14px | 模板预览和普通内容容器 |
| `--radius-composer` | 18px | 首页生成输入框 |
| `--radius-full` | 999px | 活动页签顶部、圆形图标按钮 |

顶部导航外层圆角固定为 0；活动页签底部圆角固定为 0。

### 12.4 阴影

```css
--shadow-low: 0 1px 2px rgb(20 20 20 / 6%);
--shadow-composer: 0 14px 36px rgb(20 20 20 / 10%);
--shadow-float: 0 10px 28px rgb(20 20 20 / 14%);
--shadow-modal: 0 22px 56px rgb(20 20 20 / 18%);
```

- 模板卡片默认无大阴影，悬停最多使用 `shadow-low`。
- 生成输入框允许使用 `shadow-composer`，表达首页唯一主交互。
- 菜单和提示浮层使用 `shadow-float`。
- 模态和沉浸预览使用 `shadow-modal`。
- 阴影统一使用透明中性黑，不使用实心纯黑或带品牌红的彩色阴影。

## 13. 状态与反馈

### 13.1 模板状态

- 默认：中性文字和边界。
- 悬停：边界加深，图片轻微提亮。
- 选中：品牌红边界、小勾选、名称字重提升。
- 聚焦：清晰 2px 外焦点环。
- 禁用：只在模板确实不可用时出现，并说明原因。

### 13.2 生成状态

- 空输入：生成按钮禁用。
- 可生成：箭头按钮使用品牌红，`＋` 按钮保持中性。
- 生成中：阻止重复提交，显示真实“正在生成”，不伪造百分比。
- 部分成功：仍进入结果页，由结果页展示成功与失败页面。
- 失败：留在主页，保留输入和附件，提供明确重试。

### 13.3 页面切换

- 活动页签切换使用 180—220ms，缓动 `cubic-bezier(0.16, 1, 0.3, 1)`。
- 模板选中切换使用 140—180ms。
- 不做整页入场表演、滚动劫持或无限漂浮控件。
- 所有交互动效支持 `prefers-reduced-motion`。

## 14. 背景动效接入合同

背景动效由用户另行制作，本次界面实现只提供接入位：

- 背景层固定铺满视口，位于所有业务内容之后。
- 背景层必须 `pointer-events: none`，不得拦截点击、滚动和键盘操作。
- 动效不得改变页面结构尺寸，不能导致布局跳动。
- 导航 60% 和输入框 90% 的前景透明度是既定值，背景制作需以此验证可读性。
- 标题所在区域不额外覆盖大块白卡片；背景应为标题保留足够安静的明度区域。
- 在 `prefers-reduced-motion: reduce` 下使用静态帧或极低频变化。
- 动效加载失败时显示稳定的静态背景色或静态图，不影响生成主流程。
- 在 360、768、1440 和 1600px 宽度下分别检查导航、标题和输入文字对比度。

推荐前景分层顺序：

```text
z-index 0   背景动效
z-index 10  页面内容
z-index 30  顶部导航
z-index 40  菜单与提示
z-index 60  模态与沉浸预览
```

## 15. 响应式规则

### 桌面：≥ 1180px

- 显示完整品牌组合。
- 首页内容宽度按 90vw 展开。
- 中部页签相对视口绝对居中。
- 生成输入区最大 1040px，模板轨道使用更宽主内容。

### 平板：768—1179px

- 品牌可隐藏英文副标，但保留中文名。
- 首页左右边距 24px。
- 主标题最大字号下降，输入框保持单行主结构。
- 模板继续横向滑动。

### 手机：< 768px

- 品牌折叠为 QSAI 标记。
- 顶部导航高度 60px；中部仍保留“主页 / 全部模板”。
- 历史图标保留，不能藏进抽屉。
- 首页左右边距 16px，标题字号 `clamp(34px, 10vw, 46px)`。
- 输入框可增长；按钮组仍在右侧，文字与按钮组最小间距 16px。
- 模板卡片横向滑动，露出下一张卡片边缘。
- 360px 宽度不得出现页面级横向滚动；只有模板轨道自身可横向滚动。

## 16. 配置与组件边界

执行阶段应保持以下职责分离：

- 品牌配置：中文名、英文名和缩写。
- 模板注册配置：稳定 ID、当前展示名、常用排序、预览图、详情内容和工作流映射。
- 页面壳层：背景、顶部导航和通用内容容器。
- 生成组合器：文本、附件、键盘规则、生成状态和错误反馈。
- 模板轨道：排序、选中态、横向滚动和详情跳转。
- 结果详情：继续复用现有结果能力，不复制一套新组件。

模板展示名未来变化时，只修改集中配置；不得修改路由 ID、历史键或生成合同。

## 17. PRD 同步要求

书面设计确认后，执行阶段必须把以下结构同步进主 PRD：

- 一级导航改为全宽顶部导航，不再使用固定侧边导航。
- 首页改为一句话生成入口和常用模板，不再展示最近任务。
- 模板创建不再使用独立页面，模板从主页直接生成。
- 新增独立模板详情页 `/templates/:templateId`。
- 全部模板的“使用模板”和模板详情的“用此模板创作”都返回主页、选中模板并聚焦输入框。
- 历史只从右侧图标进入。
- 生成结果继续使用独立结果页。

原《文旅营销素材生成产品体验与界面设计规范》应同步更新或标记被本设计取代的段落，避免两份文档同时要求侧边导航和顶部导航。
