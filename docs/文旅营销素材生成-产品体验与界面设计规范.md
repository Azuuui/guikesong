## 1. 文档定位

本文档同时覆盖 UX 与 UI：

- UX 部分定义信息架构、页面层级、用户流程、页面职责、反馈、错误、空状态和响应式行为。
- UI 部分定义色彩、间距、圆角、阴影、排版、图标、组件状态和动效。
- PRD 负责产品目标、范围、业务规则和可验收需求；本文档负责界面如何组织、呈现和响应。
- 实现发现业务范围、数据合同或页面职责需要变化时，先更新 PRD；纯视觉 Token 和组件表现变化更新本文档。

本文档不包含前端代码，也不允许通过视觉改造扩展当前 MVP 的业务范围。

## 2. 设计判断

**产品类型：** 面向景区运营、宣传和营销人员的内部文旅内容创作工作台。

**目标体验：** 用户可以快速从最近任务继续工作，也可以通过视觉模板创建新素材；生成结果是核心交付物，界面本身保持克制，让旅游图片承担主要视觉表现。

**设计语言：** 清晰、专业、安静、有文旅气质，但不做营销官网、模板商城或实验性作品集。

**设计基础：** 产品型界面优先，采用稳定导航、熟悉表单、明确状态和可恢复操作；模板预览和生成结果提供内容色彩。

设计参数：

| 参数 | 数值 | 说明 |
|---|---:|---|
| 设计变化度 | 5/10 | 有层级和局部不对称，不做实验性布局 |
| 动效强度 | 3/10 | 只表达状态、反馈和层级变化 |
| 信息密度 | 6/10 | 比营销官网紧凑，比传统后台轻松 |
| 主题 | 浅色 | 适合办公室、白天和长时间创作 |
| 强调色数量 | 1 | 主操作、当前选择和键盘焦点统一使用山湖青 |

明确拒绝：

- 把模板、输入、结果和历史继续堆在一个长页面。
- AI 紫色渐变、霓虹外发光和无意义玻璃卡片。
- 蓝色与橙色同时作为主操作色。
- 所有内容统一使用白色大圆角卡片和宽阴影。
- 四个纯文字按钮代替模板视觉预览。
- 虚构生成百分比、耗时、成功率和内部阶段。
- 在线图片编辑、后置文字排版、单张图片页面重试和高级模型参数。

## 3. 信息架构

### 3.1 页面层级

```text
应用
├── 工作台 `/`
│   ├── 最近生成
│   ├── 模板快捷入口
│   └── 创建新素材
│
├── 模板中心 `/templates`
│   ├── IP 宣传海报
│   ├── 攻略种草卡
│   ├── 景区氛围大片
│   └── 人物打卡大片
│
├── 模板创建 `/templates/:templateId/create`
│   ├── 一句话需求
│   ├── 参考图上传
│   ├── 当前模板说明
│   ├── 生成状态
│   └── 提交失败恢复
│
├── 生成结果 `/results/:requestId`
│   ├── 页面缩略图
│   ├── 主图片预览
│   ├── 标题、正文和标签
│   ├── 复制与下载
│   ├── 部分成功
│   └── 沉浸预览
│
├── 历史记录 `/history`
│   ├── 最近 20 条
│   ├── 打开结果
│   ├── 单条删除
│   └── 清空历史
│
└── 历史详情 `/history/:recordId`
    ├── 复用结果详情
    ├── 复制与下载
    ├── 重新生成
    └── 删除本机记录
```

### 3.2 层级职责

| 层级 | 页面 | 职责 |
|---|---|---|
| 一级 | 工作台 | 开始新任务、查看最近任务、进入常用模板 |
| 一级 | 模板中心 | 理解并选择四类模板 |
| 一级 | 历史记录 | 管理当前浏览器保存的最近 20 条结果 |
| 二级 | 模板创建页 | 完成一次生成所需输入与参考图 |
| 三级 | 生成结果详情 | 查看、复制、下载和重新生成整套素材 |
| 三级 | 历史结果详情 | 从本机历史恢复同一套结果体验 |

### 3.3 跨页面规则

- 工作台不展示完整生成表单和完整历史列表。
- 创建页不向下追加结果和历史。
- 生成成功或部分成功后进入独立结果详情。
- 当前结果与历史结果使用同一 `ResultDetail` 组件结构。
- 创建页返回模板中心；新结果返回工作台；历史详情返回历史记录。
- 浏览器前进、后退和刷新必须符合路由直觉，不使用强制跳转破坏历史栈。
- 创建失败保留模板、文字和仍有效的参考图选择。
- 刷新结果页从本机历史恢复，不重新调用模型。
- 重新生成创建新历史，不覆盖旧记录。

## 4. 应用框架

### 4.1 桌面端

- 左侧导航宽度：224px。
- 顶部页头高度：64px。
- 主内容最大宽度：1280px。
- 页面左右内边距：32px。
- 左侧导航固定，业务内容独立滚动。
- 一级导航只包含工作台、模板中心和历史记录。
- 导航底部显示真实运行模式和“记录保存在本机”说明。
- 导航与内容通过表面色差分层，不使用宽阴影。

### 4.2 平板端

- 768-1180px 时左侧导航折叠为 72px 图标栏或安全抽屉。
- 页面左右内边距：24px。
- 创建页和结果页的多栏结构按页面规则重排。

### 4.3 手机端

- 小于 768px 取消固定侧边导航。
- 顶部导航高度：56px。
- 使用菜单按钮、当前页面标题和导航抽屉。
- 页面左右内边距：16px。
- 主要操作放在业务内容中；创建页允许底部粘性生成操作，并保留安全区域。

## 5. 工作台

### 5.1 有历史时

- 页面头部包含标题、说明和唯一主按钮“创建新素材”。
- 主内容使用 8/12 最近任务与 4/12 模板快捷入口。
- 最近任务使用列表，不给每条任务套独立大卡片。
- 模板入口使用真实缩略图、小标题和一句话用途。
- 最近任务显示缩略图、任务标题、模板、真实时间、状态和成功页面数量。
- 列表更多菜单包含重新生成和删除本机记录。

### 5.2 无历史时

空状态文案：

```text
开始创建第一套文旅素材

选择一个模板，输入一句话需求，系统会生成文案、标签和完整图片页面。
```

- 直接展示四个模板视觉入口。
- 不显示“本机历史 0/20”作为主内容。
- 不使用大面积空白和悲观的“暂无数据”。

### 5.3 加载与读取失败

- 最近任务使用与最终列表同形状的骨架。
- 模板缩略图预留比例，避免布局跳动。
- 历史读取失败不阻止创建新素材。
- 单张历史缩略图损坏时保留任务记录和统一占位。

## 6. 模板中心

### 6.1 内容结构

- 桌面端使用 2×2 模板视觉画廊，间距 24px。
- 手机端使用单列，间距 16px。
- 图片区域统一使用 16:10 比例。
- 模板图片必须是真实示意图、已有生成结果或项目内明确占位素材。
- 不使用 CSS 色块、假界面和手绘 SVG 冒充模板效果。

### 6.2 模板文案

| 模板 | 用途 |
|---|---|
| IP 宣传海报 | 围绕角色形象生成活动主视觉和宣传文案 |
| 攻略种草卡 | 把景点、路线和玩法整理成多页图文内容 |
| 景区氛围大片 | 突出自然风景、季节氛围和景点卖点 |
| 人物打卡大片 | 生成人物旅拍、打卡场景和社交传播内容 |

- 卡片稳定展示标题、正文、标签、动态图片页面和可选参考图能力。
- 动态页面数量未固定时不得写死页数。
- 统一操作文案：“使用模板”。

### 6.3 模板卡片状态

- 默认：12px 圆角、1px 中性边界、无明显阴影。
- 悬停：边界转为浅山湖青，图片最大放大 1.015 倍，160ms。
- 聚焦：2px 山湖青焦点环，外偏移 2px。
- 按下：缩小至 98%。
- 图片失败：保留卡片内容和入口，显示统一中性占位。

当前只有四个模板，不增加搜索、筛选、排序、分页、收藏和自动推荐。

## 7. 模板创建页

### 7.1 桌面结构

- 使用 7/12 创作输入与 5/12 模板说明分栏，栏间距 32px。
- 右侧模板说明可在桌面端粘性停留。
- 左侧是一个完整表单区域，不把每个字段装进独立小卡片。
- 页面头部包含面包屑、模板名称、用途和“更换模板”次要操作。

### 7.2 一句话需求

- 标签始终显示在输入框上方。
- 帮助文字位于标签下方。
- 文本区域最小高度：144px。
- 字数范围：2-500。
- 右下角显示字数，450 字后进入提醒状态。
- 初次输入不足 2 字时不立即报错，提交后显示字段级错误。
- 占位符不能代替标签。

推荐错误文案：

```text
请至少输入 2 个字，让系统知道你想生成什么。
```

### 7.3 参考图上传

- 标题：“参考图片，可选”。
- 说明：“最多 4 张，支持 JPG、PNG、WebP，单张不超过 10MB。”
- 使用完整上传区域，不使用浏览器原生文件控件作为最终外观。
- 选中后显示缩略图、文件名、大小、状态和移除操作。
- 状态包括待上传、正在上传、上传成功和上传失败。
- 单文件错误保留其他合法文件和文字输入。
- 不承诺人物或 IP 一致性。

### 7.4 模板说明

右侧展示：

- 真实示例图。
- 模板名称和用途。
- 适用场景。
- 推荐输入内容。
- 参考图建议。
- 动态输出说明。

右侧不展示内部提示词、模型名称、采样参数、不可靠耗时、成功率和虚构评价。

### 7.5 主操作与状态

统一按钮：“开始生成”。

| 状态 | 文案 | 行为 |
|---|---|---|
| 默认 | 开始生成 | 可提交 |
| 输入无效 | 开始生成 | 禁用并提供原因 |
| 上传中 | 正在上传参考图 | 禁止重复提交 |
| 生成中 | 正在生成素材 | 禁止重复提交和切换模板 |
| 请求失败 | 重新生成 | 保留全部输入 |
| 成功 | 无 | 进入结果详情 |

真实可知阶段：校验内容、上传参考图、等待生成响应、保存本机记录。后端未提供时不得展示百分比、图片页进度和预计剩余时间。

### 7.6 手机端

- 顺序为模板简要信息、需求、参考图、生成与保存说明、开始生成。
- 示例图不超过首屏高度的 30%。
- 详细模板说明进入可展开区域。
- 上传缩略图横向滚动。
- 主按钮使用底部粘性操作区，并为正文预留底部空间。

## 8. 结果详情

### 8.1 页面头部

- 显示面包屑、生成标题、模板、真实时间和状态。
- 主操作：“下载素材包”。
- 次要操作：“重新生成”。
- Ghost 操作：“返回工作台”或“返回历史记录”。
- 标题优先使用生成标题；无有效标题时使用用户输入前 30 个字符。
- 不把 `requestId` 当作用户标题。

### 8.2 桌面三栏

- 左侧缩略图：180-200px。
- 中央图片预览：自适应主要空间。
- 右侧文案：320-360px。
- 栏间距：24px。
- 三栏通过表面色差、分隔线和对齐建立层级，不各自套厚重卡片。

### 8.3 页面缩略图

- 动态读取 `pages`，不假设固定页数。
- 页面角色显示为封面、内容页和结尾页。
- 选中状态使用 2px 山湖青边界和浅主色背景。
- 失败页面保留原始顺序，并使用统一失败占位。
- 缩略图可使用 `cover`，完整预览必须使用 `contain`。

### 8.4 主图片预览

- 使用 `#EEF2F3` 中性背景帮助识别图片边缘。
- 图片完整显示，不裁切，不加设备模型框和装饰网格。
- 图片周围保留 24-32px 空间。
- 图片加载时预留尺寸。
- 提供“下载此页”和“查看大图”。
- 点击图片进入沉浸预览。

### 8.5 文案区

- 标题完整显示，18-20px，字重 600。
- 正文 14px，行高 22-24px，保留合理换行。
- 标签使用浅山湖青背景和深山湖青文字，胶囊圆角只用于标签。
- 标题、正文和标签分别复制。
- 成功反馈显示“已复制”1.5-2 秒；失败提示靠近对应操作。
- 文案使用只读展示，不伪装为可编辑输入框。

### 8.6 下载与重新生成

- 下载素材包按钮加载时保持宽度。
- 部分成功时明确素材包只包含成功图片和完整文案。
- 下载失败不破坏当前结果，允许继续单图下载。
- 重新生成前说明会创建新结果并保留旧历史。
- 不提供单张图片页面重试。

## 9. 沉浸式图片预览

- 使用深灰遮罩 `rgba(17, 25, 29, 0.92)`，不使用纯黑。
- 保持图片完整比例，不加厚重相框。
- 显示当前页面角色与真实序号。
- 提供下载此页、上一页、下一页和关闭。
- `Esc` 关闭，方向键切换，Tab 可访问所有操作。
- 焦点限制在预览层内，关闭后返回触发元素。
- 手机端保留可见前后按钮，手势只能作为增强。
- 背景页面停止滚动。
- 开关动效 180-220ms，减少动效模式下直接淡入淡出。
- 不出现编辑、裁剪、滤镜、添加文字和重新排版入口。

## 10. 部分成功与失败

### 10.1 部分成功

顶部使用浅琥珀色说明：

```text
部分页面未生成成功

文案和 3 张图片可以正常使用，另有 1 张图片生成失败。
下载素材包时只会包含成功页面。
```

- 明确成功数量和失败数量。
- 不使用全屏红色错误。
- 失败页面保留原始顺序。
- 选中失败页面时显示业务化原因和“重新生成整套素材”。
- 不显示 Provider 原始响应、模型地址、完整提示词、堆栈或密钥。

### 10.2 全部图片失败

- 状态仍为 `partial`。
- 完整文案保持可见并可复制。
- 素材包仍可下载文案文件，并明确不包含图片。
- 提供重新生成整套素材，不提供单张图片页面重试。

### 10.3 结果恢复失败

```text
这条生成结果已经不在当前浏览器中

它可能已被删除，或当前浏览器不是生成时使用的浏览器。
```

提供“返回工作台”和“查看历史记录”，不显示技术 404 或 IndexedDB 错误。

## 11. 历史记录与历史详情

### 11.1 历史列表

- 最多 20 条，按保存的 `createdAt` 倒序。
- 使用今天、昨天和更早分组。
- 每条显示真实缩略图、标题、模板、时间、状态和成功页面数量。
- 整行和“查看结果”进入 `/history/:recordId`。
- 更多菜单包含重新生成和删除本机记录。
- 不在列表放完整下载操作。
- 数据最多 20 条时不增加搜索、筛选、排序和分页。

时间显示：

| 范围 | 格式 |
|---|---|
| 当天 | 今天 14:32 |
| 前一天 | 昨天 18:06 |
| 当年更早 | 08月21日 10:15 |
| 跨年 | 2025年12月28日 16:40 |

### 11.2 历史详情

- 复用结果详情组件和操作。
- 顶部显示“来自本机历史”和真实生成时间。
- 不显示保存按钮，不再次写入相同历史。
- 重新生成创建新历史，不覆盖旧记录。
- 原参考素材失效时恢复模板和文字需求，引导重新上传。

### 11.3 删除单条

确认文案：

```text
删除这条本机历史？

这条记录将从当前浏览器中删除。后端保存的参考图不会被删除。
```

- 删除入口只放在更多菜单和历史详情更多操作。
- 默认焦点放在取消或关闭。
- 删除失败保留记录并显示错误。

### 11.4 清空历史

- 明确显示将删除的实际数量。
- 明确只影响当前浏览器，不删除已下载文件和后端参考图。
- 空历史时隐藏清空操作。
- 不要求输入确认文字。
- 清空失败说明剩余记录数量。

### 11.5 历史空状态

从未生成：

```text
还没有生成记录

完成第一套素材后，标题、正文、标签和图片会自动保存在这里。
```

主动清空：

```text
本机历史已经清空

你可以继续创建新素材，新的结果会重新保存在这里。
```

读取失败不阻止创建和下载新素材。

## 13. 间距、圆角与阴影

### 13.1 4px 间距网格

| Token | 数值 | 用途 |
|---|---:|---|
| `--space-1` | 4px | 微型间距 |
| `--space-2` | 8px | 图标与文字、紧凑内容 |
| `--space-3` | 12px | 标签、小按钮内部 |
| `--space-4` | 16px | 标准组件间距 |
| `--space-5` | 20px | 表单字段之间 |
| `--space-6` | 24px | 容器内部、内容组之间 |
| `--space-8` | 32px | 页面区块和多栏间距 |
| `--space-10` | 40px | 主要内容区上下间距 |
| `--space-12` | 48px | 页面大区块 |
| `--space-16` | 64px | 少量页面级留白 |

- 同一信息组内部使用 8-12px。
- 不同字段之间使用 20px。
- 不同功能组之间使用 24-32px。
- 禁止继续新增 10px、14px、18px、22px 等无语义间距。

### 13.2 圆角

| Token | 数值 | 用途 |
|---|---:|---|
| `--radius-sm` | 6px | 小标签、缩略图内部元素 |
| `--radius-md` | 8px | 输入框、普通按钮、菜单项 |
| `--radius-lg` | 12px | 模板卡片、上传区、结果容器 |
| `--radius-xl` | 16px | 大图预览、模态窗口 |
| `--radius-full` | 999px | 状态与标签，不用于普通卡片 |

- 按钮和输入框统一 8px。
- 普通内容容器统一 12px。
- 大图和对话框最多 16px。
- 禁止 24px 以上的普通卡片圆角。

### 13.3 阴影

```css
--shadow-low: 0 1px 2px rgb(18 45 50 / 0.06);
--shadow-mid: 0 6px 14px rgb(18 45 50 / 0.10);
--shadow-high: 0 18px 40px rgb(18 45 50 / 0.16);
```

- 普通页面容器默认无阴影，使用表面色差或 1px 边界。
- 卡片悬停最多使用 `shadow-low`。
- 下拉菜单和浮层使用 `shadow-mid`，不再叠加厚边框。
- 弹窗和沉浸预览使用 `shadow-high`。
- 阴影颜色使用深青灰，不使用纯黑。
- 禁止普通白卡片统一使用宽阴影。

## 15. 组件规范

### 15.1 按钮

- 标准高度：40px。
- 主操作高度：44px。
- 统一 8px 圆角。
- 类型：Primary、Secondary、Ghost、Danger。
- 状态：默认、悬停、聚焦、按下、禁用、加载。
- 按钮文字不换行。
- 相同意图统一文案，例如始终使用“开始生成”。
- 按下可缩小至 98%，不能使用夸张弹跳。

### 15.2 输入框

- 标签在上，帮助文字可见，错误在下。
- 标准高度 44px，文本区域最小高度 144px。
- 默认中性边界，聚焦使用主色边界和 2px 焦点环。
- 占位文字满足对比度，不代替标签。
- 禁用状态仍保持可读。

### 15.3 上传器

- 使用明确上传区域和缩略图列表。
- 提供格式、数量和大小说明。
- 每张文件显示本地状态和可操作移除。
- 单文件失败不清空其他文件。

### 15.4 状态标签

- 只表达真实状态：已完成、生成中、部分完成、失败、Mock 模式。
- 可以使用胶囊圆角。
- 同时使用图标、文字和语义色。
- 禁止把状态点当作页面装饰。

### 15.5 浮层与对话框

- 下拉菜单通过 Portal、固定定位或原生 Popover/Dialog 脱离裁切容器。
- 对话框只用于重新生成确认、单条删除和清空历史等明确场景。
- 支持 `Esc`、焦点限制和关闭后焦点恢复。
- 危险操作默认焦点不放在确认按钮。

## 16. 动效与加载

| 动效 | 时长 | 用途 |
|---|---:|---|
| 快速反馈 | 120-160ms | 按钮悬停、按下 |
| 标准切换 | 180-220ms | 标签切换、面板、预览 |
| 页面状态 | 220-280ms | 抽屉、结果状态转换 |

统一缓动：

```css
cubic-bezier(0.16, 1, 0.3, 1)
```

- 不做整页入场表演、滚动劫持和无限漂浮。
- 加载使用与最终内容同形状的骨架，不使用页面中央孤立转圈。
- 动画不控制内容是否可见。
- 所有动效支持 `prefers-reduced-motion`。
- 不使用 React state 跟踪连续滚动或鼠标坐标。

## 17. 响应式与无障碍

代表宽度：360px、390px、768px、1024px、1440px、1600px。

验收要求：

- 360px 下无页面横向滚动。
- 桌面导航保持单行和稳定宽度。
- 多栏布局在小屏明确转为单列或横向缩略图。
- 按钮文字不换行，主操作始终可访问且不遮挡正文。
- 上传缩略图、长标题、长文件名和 500 字输入不会撑破布局。
- 普通文字对比度至少 4.5:1，大文字至少 3:1。
- 所有可交互元素有可见焦点。
- 点击区域不小于 44×44px。
- 模板选择、上传移除、图片切换、复制、下载和历史操作支持键盘。
- 图片有符合内容的替代文字。
- 状态不只通过颜色表达。
- 错误靠近错误字段，不使用浏览器 `alert()`。

## 19. 最终设计验收

- [ ] 工作台、模板中心、创建页、结果页、历史页不再纵向堆叠成单页。
- [ ] 固定导航、面包屑和浏览器历史共同表达一级、二级和三级页面关系。
- [ ] 工作台有历史时任务优先，无历史时直接引导创作。
- [ ] 四个模板使用真实视觉入口，不使用纯文字按钮。
- [ ] 创建页只有一个生成任务，不暴露模型参数和内部提示词。
- [ ] 生成状态只展示真实可知阶段，不伪造进度。
- [ ] 结果页使用缩略图、主预览和文案操作三栏，并在小屏正确重排。
- [ ] 当前结果与历史结果复用同一组件结构。
- [ ] 部分成功保留失败页面顺序和完整文案。
- [ ] 沉浸预览只负责查看、切换和下载，不出现编辑功能。
- [ ] 历史时间来自保存的 `createdAt`，刷新不会变化。
- [ ] 删除和清空只影响当前浏览器，不误导用户认为后端参考图已删除。
- [ ] 色彩、间距、圆角、阴影和排版只使用本文档定义的 Token。
- [ ] 普通页面平面优先，阴影只表达真实浮层。
- [ ] 所有适用组件具有默认、悬停、聚焦、按下、禁用、加载和错误状态。
- [ ] 360px 到 1600px 截图无阻断性溢出、遮挡和按钮换行。
- [ ] 键盘可以完成模板选择、输入、上传、生成、图片切换、复制和下载主流程。
- [ ] 控制台无 React key 错误、资源 404 和未处理 Promise 错误。

## 20. 实施边界

本文档确认的是产品体验和界面设计，不授权增加以下能力：

- 登录、账户、权限和跨设备同步。
- 模板搜索、筛选、收藏、推荐和模板市场。
- 提示词编辑、模型选择和高级参数。
- 在线图片编辑、文字替换、裁剪、滤镜和人工套版。
- 单张图片页面重新生成。
- 后端参考图删除和自动清理。
- 云端素材管理和社交平台发布。

这些能力如需加入，必须先回到 PRD 单独评审。
