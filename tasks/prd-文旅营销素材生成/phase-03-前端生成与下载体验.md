# Phase 3：前端生成与下载体验

Parent PRD：[PRD：文旅营销素材生成 Demo](../prd-文旅营销素材生成.md)
Status：Not Started
Last Updated：2026-08-28

## 目标

实现简洁的单页生成体验，让用户选择模板、输入一句话、查看整套结果、复制文案并下载图片和素材包。

## 对应范围

- Goals：G-1、G-2、G-5
- Success Criteria：SC-1、SC-2、SC-5—SC-8
- Requirements：FR-1—FR-3、FR-12—FR-14、FR-18、NFR-1、NFR-4—NFR-6

## Phase Discovery Gate

- [ ] 阅读主 PRD、共享 DTO、Generate API 测试和真实响应示例。
- [ ] 检查现有前端结构与设计模式，不把所有状态写入 `App.tsx`。
- [ ] 核对图片数据形式是否支持浏览器预览和下载。
- [ ] 核对目标手机/桌面浏览器的 Clipboard 与下载兼容边界。
- [ ] 若下载包格式变化，先更新 PRD 和 API/前端合同。

## 范围

### In Scope

- 模板选择、文字输入、生成按钮、加载/错误/部分成功状态。
- 标题、正文、标签、动态页面展示。
- 复制、单图下载、完整素材包下载和响应式布局。

### Out of Scope

- 登录、历史、富文本编辑、提示词编辑、图片上传、单页重试和发布平台集成。

## 实施清单

- [ ] 创建模板选择组件，以四个固定模板 ID 驱动，不在 UI 复制后端提示词。
- [ ] 创建一句话输入组件，显示 2—500 字校验和清晰示例。
- [ ] 创建生成状态 hook/service，处理 idle、loading、success、partial、error，并阻止重复提交。
- [ ] 创建 API client，严格使用共享 `GenerateRequest/Response` 类型。
- [ ] 创建结果文案组件，分别展示并复制标题、正文和标签。
- [ ] 创建动态页面画廊，展示成功图片和失败页面状态。
- [ ] 实现单图下载，使用后端文件名并处理跨域/Blob 异常。
- [ ] 实现素材包下载，包含成功图片和 UTF-8 文案文件；失败页面在文案或清单中说明。
- [ ] 实现重新生成整套素材，保留当前模板和用户输入。
- [ ] 完成桌面与手机布局，生成中保持页面可读且不锁死浏览器。
- [ ] 编写模板选择、输入校验、重复提交、成功、partial、失败、复制和下载组件测试。
- [ ] 更新 README 使用说明，并用中文 Commit Message 提交。

## 验证策略

组件测试覆盖状态与操作，真实浏览器覆盖 Clipboard、Blob/ZIP 下载和响应式行为；不需要视觉生成质量自动化判断。

## 验证清单

- [ ] 空输入、过短和过长输入无法提交并有明确提示。
- [ ] 生成中按钮禁用，连续点击只发送一个请求。
- [ ] 成功响应正确展示文案与全部页面。
- [ ] `partial` 响应展示成功页面和失败提示，不隐藏文案。
- [ ] 标题、正文和标签复制内容准确。
- [ ] 单图及素材包在桌面和手机宽度浏览器中可触发下载。
- [ ] 前端单元测试、typecheck 和 production build 通过。

## 退出标准

- [ ] 用户可以完成从输入到下载的完整前端流程。
- [ ] 所有 GenerateResponse 状态均有明确 UI。
- [ ] Phase 4 只剩联调、质量和交付问题。
