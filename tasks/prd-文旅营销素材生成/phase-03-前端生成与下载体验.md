## 目标

把单页 Demo 重组为多页面黔景智作产品，并在正式首页增补中将常用生成前置到主页：实现模板选择、需求输入、参考图上传、结果查看、复制下载和本机历史管理，统一主页、模板、结果与历史的设计系统和结果组件。

## 范围

### In Scope

- 固定侧边导航的应用框架，以及工作台、模板中心和历史记录一级入口。
- 四模板视觉入口和独立模板创建页。
- 一句话输入、参考图选择/预览/移除、上传状态和生成状态。
- 独立结果详情、动态页面缩略图、主图片预览、文案复制、单图和素材包下载。
- 沉浸式图片查看、键盘关闭和前后切换。
- 成功、部分成功、全部图片失败、请求失败、空状态和读取失败。
- IndexedDB 最近 20 条完整历史、结果恢复、单条删除和清空。
- 360px 到 1600px 的响应式布局、键盘焦点、对比度和减少动效支持。
- 山湖青、冷灰、4px 间距网格、角色圆角、平面优先阴影和统一排版 Token。

### Out of Scope

- 登录、跨设备历史、云端素材管理、收藏、文件夹和团队协作。
- 模板搜索、筛选、排序、自动推荐和模板市场。
- 提示词编辑、模型参数、高级图片规格和多步骤向导。
- 富文本编辑、图片裁剪、Canvas/SVG 二次排版、滤镜和在线图片编辑。
- 单张图片页面重新生成、后端素材删除和社交平台发布。
- 为视觉效果增加虚构进度、生成耗时、成功率或用户评价。

## 实施清单

### A. 页面与应用框架

- [x] 拆分当前单体 `App`，建立应用框架、页面、功能组件、数据访问和设计 Token 的清晰边界，避免把路由、上传、生成、下载和历史继续集中在一个文件。
- [x] 建立 `/`、`/templates`、`/templates/:templateId/create`、`/results/:requestId`、`/history` 和 `/history/:recordId` 路由；刷新、前进和后退待用户手动验证。
- [x] 创建桌面固定侧边导航、平板折叠导航和手机顶部导航/抽屉；一级导航只包含工作台、模板中心和历史记录。
- [x] 实现统一页面标题、面包屑和主操作区域，保证每个页面只有一个主要意图。
- [x] 建立路由级加载、结果不存在和历史读取失败状态，禁止静默跳回工作台。

### B. 工作台与模板中心

- [x] 创建任务优先工作台：有历史时展示最近任务和模板快捷入口，无历史时直接引导创建第一套素材。
- [x] 最近任务显示真实缩略图、标题、模板、保存的 `createdAt`、状态和成功页面数量；不得在渲染时生成当前时间。
- [x] 创建四模板视觉画廊，使用项目内模板预览素材，不以四个纯文字按钮代替模板预览。
- [x] 模板卡片展示用途、动态输出和参考图能力；不把内部提示词、模型参数或不可靠页数暴露给用户。
- [x] 工作台模板快捷入口与模板中心进入同一创建页，不维护两套表单。

### C. 模板创建页

- [x] 为四个固定模板建立独立创建页，共用表单骨架并由模板配置提供用户可见名称、用途、示例和参考图建议。
- [x] 创建一句话输入组件，提供固定标签、帮助文字、2—500 字校验、字数计数和清晰错误，不用占位符代替标签。
- [x] 创建参考图上传组件，限制最多 4 张 JPG/PNG/WebP、单张 10MB，支持缩略图、移除、客户端校验和单文件错误保留。
- [x] 创建 Reference Assets API client，生成前上传合法文件，上传成功后只向生成接口传 `assetId`。
- [x] 创建生成状态服务，区分可真实确认的校验、上传、生成请求和本机保存状态；生成中阻止重复提交和模板切换。
- [x] 请求失败时保留模板、文字和仍有效的参考图选择；错误使用字段级或页面内提示，移除浏览器 `alert()`。
- [x] 生成成功或部分成功后先保存本机结果，再进入独立结果详情；保存失败时仍进入结果页并提示优先下载素材包。

### D. 结果详情与沉浸预览

- [x] 创建统一 `ResultDetail` 结构，使当前结果和历史结果复用页面头部、状态提示、缩略图列表、主预览、文案面板和下载操作。
- [x] 动态读取 `pages`，用中文显示封面、内容页和结尾页；失败页面保留原始顺序，不假设固定页面数量。
- [x] 主图片预览使用完整比例和 `contain`，缩略图可以裁切；图片加载时预留尺寸，避免布局跳动。
- [x] 创建标题、正文和标签展示及独立复制反馈，复制成功短暂显示“已复制”，复制失败不影响其他结果。
- [x] 实现当前图片下载和素材包下载；部分成功时明确素材包只包含成功图片和完整文案。
- [x] 实现重新生成整套素材，创建新结果和新历史，不覆盖旧记录；恢复文字并提示参考图片需要重新上传。
- [x] 创建沉浸式图片预览，支持关闭、前后切换、单图下载、`Esc`、方向键、焦点限制和关闭后的焦点恢复。
- [x] 实现 `partial` 顶部说明、成功/失败数量、失败缩略图和业务化错误；全部图片失败时仍展示和下载完整文案。

### E. 本机历史

- [x] 创建 IndexedDB repository，保存模板、用户输入、参考图本地副本、生成文案、页面图片 Blob、状态和真实 `createdAt`。
- [x] 成功或部分成功后自动保存，最多保留最近 20 条；写入第 21 条时删除最旧本机记录。
- [x] IndexedDB 配额不足时先删除最旧记录并重试；仍失败时保留当前结果并显示非阻断提示。
- [x] 创建历史列表，按真实时间倒序并以今天、昨天和更早分组；最多 20 条时不增加搜索、筛选和分页。
- [x] 创建历史详情数据加载器，将本机记录转换为统一结果结构，禁止为历史另写一套结果 UI。
- [x] 实现单条删除和清空确认，明确只删除当前浏览器记录，不删除后端参考素材和已下载文件。
- [x] 创建从未生成、主动清空、读取失败和浏览器无法保存等独立空状态。

### F. 设计系统、响应式与无障碍

- [x] 按 UX/UI 规范建立颜色、间距、圆角、阴影、排版、层级和动效 Token，移除旧单页样式。
- [x] 使用单一山湖青主色和冷灰中性色；模板图片负责内容色彩，语义色只表达成功、警告、错误和信息。
- [x] 建立按钮、输入框、上传器、模板卡片、任务列表、状态标签、浮层和对话框的状态样式。
- [x] 普通内容以表面色差和细边界分层，明显阴影只用于浮层、菜单、沉浸预览和弹窗。
- [x] 实现响应式断点与小屏单列/横向缩略图布局；360px、390px、768px、1024px、1440px 和 1600px 实际表现待用户手动验证。
- [ ] 验证正文和控件对比度、44×44px 最小点击区域、可见焦点、键盘导航、图片替代文字和状态非颜色表达。
- [x] 所有动效只表达状态和层级，常规时长 120-280ms，并提供 `prefers-reduced-motion` 降级。
- [x] 使用单一 Phosphor 图标家族，不混用 emoji、手绘 SVG 和多个图标库。

## 验证策略
